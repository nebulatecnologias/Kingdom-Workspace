# Surface: Kingdom Members clickable prototype

Scope: every screen of the members area in one clickable file — emails (invite, sign-in link, pack unlocked), invite account creation, link expired/used + request new link, login (email link / password), member library with locked packs, pack page with on-screen colouring, profile, admin (overview, invites, members, showcase, pack editor, integrations). Sample data only.

Mode: Operate (member and admin tasks); emails are Read.

Audience/job: SA buyers on phones reaching their pages; the owner running invites, showcase and gateway integration on a laptop.

Constraints: EN (en-ZA) / PT / ES switch across UI and emails; ZAR; A4; mobile-first; POPIA controls.

## Direction contract

THESIS: The pinned Ware Sync dashboard world carries the whole product; the pack artwork is the only loud thing. Refuses the generic LMS course grid and the cream-and-serif "kids' faith" look.

OWN-WORLD: Warm grey-white canvas, white soft-gradient cards (22px radius, offset soft shadows), orange gradient pill CTAs with split dropdown, green status pills, violet countdown card, mention/order chips in the activity feed, orange five-bar mini charts, Google Sans only. Pastel pack fields with thick-line colouring art.

STORY: Member understands what they own in one glance, opens a pack, prints or colours; sees locked packs with price and unlocks through the gateway. Admin sees members, expiring invites and gateway events at a glance and controls the showcase.

FIRST VIEWPORT: Library — sidebar (logo, nav) left; greeting; filter chips; pack grid where owned covers are coloured and locked covers are line-art with padlock and price pill. Admin overview mirrors the reference: KPI cards row, violet "next invite expires" countdown, activity feed right.

FORM: Pinned by the user (reference screenshot + logo + font); no roll — user-pinned direction beats the roll. Signature interaction: tap-to-colour page preview. Seed key: none (pinned).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
